# GeneSpace Synteny & Orthology Pipeline

This pipeline automates the comparative genomics workflow, spanning from raw protein annotations to chromosome-level synteny visualization. It integrates OrthoFinder for orthology inference, MCScanX for synteny block detection, and GeneSpace for pangenome and riparian visualization.

## 1. Pipeline Overview
1. Data Preparation: Standardizing and reformatting input protein sequences and annotations into GeneSpace-compatible formats (GFF3 and PEP).
2. Orthology Inference: Executing all-vs-all protein sequence alignment and clustering using OrthoFinder.
3. Synteny Analysis: Identifying collinear blocks and gene-order conservation using MCScanX.
4. Visualization: Generating riparian plots to visualize chromosome-level synteny and structural evolution across multiple species.

## 2. Input File Formats

### A. Longest Isoform Protein FASTA (*.longest_isoform.prot.fa)
The core input file for each species. It must include positional metadata in the header.
- Format: >ProteinID Chromosome:Start-End(Strand)
- Example:
  >XP_001234567.1 CM014885.1:10234-12500(+)
  MKAILVLVTLA...

### B. Species Directory Structure
The pipeline iterates through a specified directory where each subdirectory represents a species.
- Format: /path/to/species_data/[SpeciesName]/[SpeciesName].longest_isoform.prot.fa

## 3. Output Files

### A. rundir/rawGenomes/[Species]/1/annotation/
- Description: Standardized inputs generated by `prep_funannotate_genome.php`.
- Files: 
  - [Species].gene.gff.gz (GFF3 format with 'locus' tags)
  - [Species].pep.fa.gz (Formatted peptide FASTA)

### B. rundir/orthofinder/
- Description: Raw output from OrthoFinder.
- Files: Hierarchical orthogroups (HOGs), orthogroup sequences, and sequence alignment files.

### C. rundir/synteny/
- Description: MCScanX collinearity outputs showing conserved gene clusters between species pairs.

### D. rundir/plots/ (or output in R)
- Description: Riparian plots (PDF/PNG) showing syntenic blocks across chromosomes and pangenome statistics.

## 4. Usage Workflow

1. Data Integration & Formatting:
   - Place all `*.longest_isoform.prot.fa` files into their respective species subdirectories.
   - Run `prep_funannotate_genome.sh` to batch-convert all sequences into the GeneSpace-compatible directory structure.

2. Configuration:
   - Open `run.R` and update the `genomeIDs`, `speciesIDs`, and `versionIDs` arrays.
   - Configure external software paths (`path2orthofinder`, `path2mcscanx`, etc.) according to your local environment.

3. Execution:
   - Run the R script via the provided wrapper:
     `./runR.sh`
   - This executes the full pipeline: parsing annotations -> orthofinder clustering -> synteny analysis -> pangenome calculation.

4. Visualization:
   - The final segment of `run.R` generates the riparian visualization. Modify the `datInvert` or `regs` dataframes within the script to adjust chromosome orientation or highlight specific syntenic regions.
