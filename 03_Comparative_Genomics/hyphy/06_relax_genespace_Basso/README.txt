# RELAX Selection Analysis Pipeline

This pipeline automates large-scale molecular evolutionary analysis using the HyPhy RELAX method. It evaluates whether selective pressure on specific "foreground" branches of a phylogenetic tree has been relaxed or intensified compared to "background" reference branches across hundreds or thousands of orthogroups.

## 1. Pipeline Overview
1. Alignment Integration: Parses codon-aligned nucleotide sequences and matches them with pre-labeled Newick trees.
2. Quality Control: Performs automated screening for premature stop codons and validates sequence length consistency to ensure model robustness.
3. Evolutionary Inference: Executes HyPhy RELAX to estimate the selection intensity parameter (K) and conduct likelihood ratio tests against null models.
4. Result Consolidation: Aggregates statistical metrics (P-values, K, Omega distributions) and gene annotations into a standardized summary table.

## 2. Input File Formats

### A. ret_improved_cleanDNA.fasta
The aligned nucleotide sequence file for orthogroups.
- Format: FASTA with specific metadata tags.
- Example Header: 
  >Ortho:[ID];Sp:[Taxon];MappedToRef:[Ref];SpGeneId:[ID];GroupId:[OG_ID]

### B. Tree Folder (*.txt)
A directory containing Newick-formatted trees for each orthogroup, requiring branch labels for RELAX analysis.
- Format: [GroupId].txt containing Newick strings with {T} (Test/Foreground) and {R} (Reference/Background) tags.
- Example: ((SpeciesA{T},SpeciesB{T}){T},SpeciesC{R});

### C. genespace.orthogroups.txt
Mapping file linking Orthogroups to functional gene symbols.
- Format: Tab-delimited (GroupId | GeneSymbol | Description)
- Example:
  Group_0_0    hif1a    hypoxia-inducible factor 1-alpha

## 3. Output Files

### A. ret_partX.of.Y.txt
- Description: The primary results file containing statistical outputs for each orthogroup.
- Key Columns: GroupID, Status (Success/Error), GeneSymbol, K (Selection Intensity), LR (Likelihood Ratio), P-value, and estimated Omega values (R_omega0, R_omega1, etc.).

### B. HyPhy Temporary Directories
- Description: Log files and intermediate results generated by the RELAX batch file, used for deep debugging or verification.

## 4. Usage Workflow

1. Setup:
   Ensure all codon-aligned sequences are in the master FASTA file and pre-labeled trees are located in the designated tree directory.

2. Parallel Execution:
   The pipeline supports parallel processing to handle large datasets. Run the script by specifying the total number of parts (-N) and the current partition index (-f):
   php hyphyrelax.php -p ret_improved_cleanDNA.fasta -T ./tree_dir -S genespace.orthogroups.txt -N 50 -f 0

3. Resumption:
   The script automatically detects previous 'Success' records in the output file and skips them, allowing for safe resumption after interruptions.

4. Statistical Interpretation:
   Analyze the K parameter in the output. A K > 1 indicates intensification of selection, while K < 1 suggests relaxation, provided the associated P-value is significant (< 0.05).
