PROJECT: HyPhy Selection & Functional Enrichment Pipeline

1. OVERVIEW
This pipeline performs downstream evolutionary selection analysis using the orthogroups
generated by GeneSpace/OrthoFinder. It covers tree inference, lineage-specific 
selection tests (RELAX), and gene ontology (GO) enrichment.

2. DIRECTORY STRUCTURE
01_genespace/       : Synteny and orthology clustering pipeline (GeneSpace).
02_assigngenesymbols/: Maps OrthoFinder groups to functional gene annotations.
03_othersp_protein/ : Protein sequence normalization and isoform deduplication.
04_exportAln_genespace/: (Link) Orthologous alignment extraction for PAML/HyPhy.
05_raxml/           : Phylogenetic tree inference (required for HyPhy/PAML).
06_relax_genespace/ : Selection analysis and functional (GO) enrichment.

3. WORKFLOW STEPS
Step 1: Genome Preparation
    - Run `01_genespace/prep_funannotate_genome.sh` to standardize GFF/FASTA.
    - Run `runR.sh` to execute the GeneSpace synteny pipeline.

Step 2: Ortholog Annotation
    - Use `02_assigngenesymbols_orthofinder/` scripts to link orthogroups to
      known gene symbols and descriptions.

Step 3: Protein Normalization
    - Execute `03_othersp_protein/prepareNCBIProteins.sh` to filter redundant 
      isoforms and standardize sequence headers.

Step 4: Tree Inference
    - Convert alignments to Phylip format via `05_raxml/convert2phylip.php`.
    - Infer trees using `05_raxml/raxml.sh` (input: in.phy).

Step 5: Selection Analysis (RELAX)
    - Run `06_relax_genespace_Basso/hyphyrelax.php` to perform selection tests.
    - Results are summarized in `sum_Basso.txt`.

Step 6: Functional Enrichment (GO)
    - Run `06_relax_genespace_Basso/GO/relax_GO.R` to compute GO term enrichment
      for genes under selection.
    - Visualize results using `plot.R`.
