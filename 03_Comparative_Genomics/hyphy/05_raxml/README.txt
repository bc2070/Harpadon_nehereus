# Phylogenomic Matrix Preparation & RAxML Pipeline

This pipeline automates the transformation of codon-aligned orthologous sequences into partitioned phylogenetic matrices. It classifies genomic data into specific evolutionary partitions (Full CDS, Codon 1st+2nd positions, and 4-fold degenerate sites) and prepares them for robust maximum likelihood tree inference using RAxML.

## 1. Pipeline Overview
1. Sequence Parsing: Extracts taxon and orthogroup identifiers from alignment headers to organize sequences for matrix construction.
2. Partitioning Logic: Decomposes coding sequences based on codon position and degeneracy, enabling targeted evolutionary analyses.
3. Matrix Formatting: Constructs Phylip-formatted files with missing data ('N') padding to maintain strict alignment integrity across all taxa.
4. Tree Inference: Executes maximum likelihood phylogenetic analysis using the GTR+GAMMA model via RAxML.

## 2. Input File Formats

### A. ret_improved_cleanDNA.fasta
The primary input file containing QC-passed, codon-aligned coding sequences.
- Format: FASTA with metadata-rich headers.
- Example Header: 
  >Ortho:[ID];Sp:[Taxon];MappedToRef:[Ref];SpGeneId:[ID];GroupId:[OG_ID]

## 3. Output Files

### A. phylipformat/full.phy
- Description: Concatenated matrix containing the full-length coding sequences.

### B. phylipformat/codon12.phy
- Description: Partitioned matrix containing only the 1st and 2nd codon positions, commonly used to minimize noise from fast-evolving 3rd positions in deep phylogenetics.

### C. phylipformat/4fold.phy
- Description: Partitioned matrix containing only 4-fold degenerate sites (sites included only if present in >= 50% of taxa), suitable for neutral evolutionary rate estimation.

### D. RAxML Output (*_allcodons.bestTree, etc.)
- Description: Inferred phylogenetic tree files in Newick format, generated by RAxML.

## 4. Usage Workflow

1. Data Conversion:
   Run the conversion script to generate the partitioned Phylip matrices from your aligned FASTA file:
   php convert2phylip.php -p ret_improved_cleanDNA.fasta -o ./phylipformat

2. Phylogeny Inference:
   Configure the `raxml.sh` script:
   - Update the `-s` flag to point to your target Phylip file (e.g., full.phy, codon12.phy, or 4fold.phy).
   - Set the `-n` flag to specify the output filename suffix to avoid overwriting previous results.
   - Run the inference:
     ./raxml.sh

3. Quality Control:
   - Check the printed gene counts per taxon in the script logs to ensure balanced sequence representation.
   - Review the `4fold.phy` matrix size; if the resulting matrix is too small, consider using the full.phy or codon12.phy matrices for more robust topological support.
